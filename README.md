# iRoute

iRoute 是一个轻量的 App Store 地区切换页面。打开页面后直接点击地区，使用 Apple 的 `resetAndRedirect` 入口切换对应 storefront，不需要二次确认。

## 使用

```bash
python3 -m http.server 8765
```

浏览器访问 `http://127.0.0.1:8765/`。在 iOS 上，地区按钮会通过 `itms-apps://` 协议直接打开 App Store。

## 结构

```text
index.html          页面和直达链接（64 个地区统一为国旗+汉字卡片）
assets/styles.css   响应式布局与视觉样式（尺寸由 CSS 变量驱动）
assets/app.js       按屏高计算国旗行数，放不下的行降级为缩写
images/icon.svg     站点图标（simple-icons 的 App Store 字标 + iOS 风格渐变底）
```

站点图标为 SVG：iOS 风格渐变圆角方块 + 白色 App Store 字标（取自 simple-icons，CC0），16–128px 均清晰，无运行时依赖。

## 响应式布局

全站一套逻辑，不区分手机/桌面：

- **列数按屏宽**：≤600px 每行 4 列，≤700px 5 列，≤900px 6 列，更宽 8 列（上限）。
- **国旗行数按屏高**：`app.js` 在加载和窗口变化时计算当前视口能放下多少行「国旗+汉字」卡片，放不下的行自动降级为两字缩写 chip（仅显示 CN、AE 等代码）。
- **第一要义是完全显示**：任何视口下 64 个地区全部一屏呈现，不滚动、不截断；屏幕够大（如桌面 1440×900、iPad 竖屏）则全部 64 个都显示国旗+汉字。
- 矮屏（高度 ≤640px）自动压缩卡片、旗面和字号，让国旗能多显示几行。
- 卡片使用半透明白底和旗面边框，避免白色国旗与背景融为一体。
- 常用地区使用统一的 `flag-icons` SVG 资源；中国台湾按钮使用中国国旗，缩写沿用 ISO 3166-1 的 `TW`。

已在 12 个视口验证无滚动且 64 项全部在屏内：`320×568`、`375×667`、`375×812`、`390×844`、`430×932`、`667×375`、`844×390`、`768×1024`、`1024×768`、`1280×720`、`1440×900`、`1920×1080`。

```bash
wrangler pages deploy . --project-name ifd9a --commit-dirty=true
```
